# 1 从线性方程组到矩阵
## 推广流程
$有限元线性方程组 \stackrel{extend\  to\  n \ element}{\longrightarrow} n元线性方程组$ 
$\Downarrow 省略未知数$
$有限级矩阵 \stackrel{extend\  to\  n \ element}{\longrightarrow} s \times n矩阵(又称n元线性方程组的系数矩阵)$
$\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \Downarrow 添加等号右边的常数$ 
$\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ s \times(n+1)矩阵（又称n元线性方程组的增广矩阵）$
