# 诗库索引

> *收下那些适合在夜里重读的诗。*

## 新建诗作

标题是诗名，正文直接写完整诗作；保存后，它会自动出现在下方列表，也会参与主页的每日随机诗。

```dataviewjs
const templatePath = '诗库/模板/诗句模板.md';
const createButton = this.container.createEl('button', { cls: 'forest-new-poem', text: '＋ 新建诗作' });

createButton.addEventListener('click', async () => {
  try {
    const fileName = `未命名诗作 ${window.moment().format('YYYY-MM-DD HHmmss')}`;
    const targetPath = `诗库/${fileName}.md`;
    const template = await app.vault.adapter.read(templatePath);
    const content = template
      .replace('<% tp.date.now("YYYY-MM-DD") %>', window.moment().format('YYYY-MM-DD'))
      .replace('<% tp.file.title %>', fileName);
    const file = await app.vault.create(targetPath, content);
    await app.workspace.getLeaf(true).openFile(file);
  } catch (error) {
    console.error('新建诗作失败', error);
    new Notice('新建失败，请检查诗库与模板文件。');
  }
});
```

也可以手动新建后套用 [[诗库/模板/诗句模板|诗歌模板]]。

## 全部诗作

```dataview
TABLE file.link as "诗作", join(filter(tags, (tag) => tag != "poetry"), " · ") as "分类标签", created as "创建于"
FROM "诗库"
WHERE type = "poem"
  AND !contains(file.path, "诗库/模板/")
SORT file.name ASC
```
