要求**数学老师推荐表**。所以如果 2027 延续相似节奏，你不能等丘赛考完再考虑暑校。我建议时间倒推：

我会把准备分成：40% Riemannian Geometry + 35% Analysis/PDE + 25% Complex Geometry prerequisites。

##### Riemannian

重点预习：Riemannian metric、Levi-Civita connection、geodesic、curvature tensor、sectional / Ricci curvature。知道 Jacobi field 是什么就很好。**不要提前把 Toponogov / Rauch 全学完**，否则暑校反而没东西学了。

##### Analysis/PDE

学到：Δu = 0 为什么是 harmonic；maximum principle；Poisson kernel；Dirichlet problem 的基本思想；Green function 大概是什么。然后保证：L^p、Hölder、Minkowski、Fubini 比较熟。

Gilbarg–Trudinger 没必要从第一章啃到底。官网把 GT、Han–Lin 列为参考书，本身就说明课程强度高，但**参考书不是入营前待办清单**。

##### Complex Geometry

这里我反而不建议你提前学太多 complex geometry 本身。保证：manifold + forms + Stokes 非常熟。如果有时间，再了解：complex manifold 是什么；almost complex structure；(p,q)-forms；∂、∂̄。足够。Hodge / Kodaira 那些东西让老师讲。

### 托福计划

#### 六级结束以后

找一套**当年最新官方 TOEFL 模考**完整做一次。这里强调“当年最新”，因为 TOEFL 近年的题型和计分方式有调整，你到时候不要拿几年前的备考流程机械套。

第一次只回答四个问题：

> 阅读是不是已经基本不用管？
> 听力能不能稳定抓结构和细节？
> 口语是不是明显短板？
> 写作能不能快速组织英文输出？

我猜你的情况很可能会是：Reading强 > Listening > Writing/Speaking 熟练度。因为长期读英文数学会把阅读抬起来，但**托福口语这种限时输出不会自动长出来**。寒假不追分，只做诊断 + 建基本习惯。

#### 大二下学期

所以托福只能每周 **2–3 小时**，甚至可以固定成两次：

- **一次 60–90 分钟听力/口语**：比如听一段 academic lecture，然后不看稿复述 1–2 分钟。
- **一次 60–90 分钟写作/综合训练**：把“知道英语”逐渐变成“能快速输出英语”。

阅读基本靠日常英文数学维持。如果大二上六级没到 500，那么大二下还要上英语（三）并准备二战六级，这时候**托福继续降级**，不要同时备 CET-6 和 TOEFL。

#### 真正的托福备考窗口：大二暑假

可以安排成 **6月底—7月底：第一轮集中训练**，每周 6–8h，足够。开始：

- 完整阅读/听力训练；
- 口语计时输出；
- 写作计时；
- 每周/两周一套完整模拟。

重点不是背海量单词。你的词汇来源应该逐渐分成：一般 academic English + 托福高频场景。数学专业词汇基本不需要专门准备。

**北大暑校期间**：暂停托福专项。白天如果真的每天几小时微分几何/PDE，晚上还刷托福非常没必要。暑校就是数学优先。

**暑校结束后 2–3 周**：进入最后冲刺 8–12h/week，做完整模考、修复最后短板，然后：**2027年8月底/9月第一次正式考试**。因为你到那时候才大三刚开始，距离真正申请还有一年多。

#### 目标设置

对于目标，不建议追求托福满分或者为了几分反复刷。申请美国强 Math PhD，语言的理想状态就是：不成为任何学校的短板。按大家熟悉的传统 120 分尺度，我会把心理 benchmark 放在：105 左右，并且口语不要明显偏低，因为有些学校的 TA 资格会另外关注 spoken English。但你真正申请大概是 **2028 年秋**，到时候各校要求、ETS 计分方式可能继续变化，所以最终不要死盯“105”这个旧制数字，而是按当年目标学校的语言要求重新统一检查。

如果第一次已经达到一个**绝大多数目标数学系都够用，而且口语也不碍 TA**的成绩：立刻收手，不要 **105 → “我要不要再刷到112？”**。**别考了，去学数学。**

如果第一次表现明显低于目标，那么大三上再给一次：**4–6周针对性二战**，而且不再全科复习。假如阅读已经非常强、听力不错、主要掉在口语，那就只狠狠干口语。争取 **2027 年底以前把 TOEFL 完全解决**。

最晚 deadline：**2028暑假以前**。到了大四申请季，我绝对不希望你还在：做 research + 写 SOP + 找推荐信 + 选校 + 刷托福。

**语言时间线：**

- 2026秋：CET6 500+
- 2027寒假：TOEFL 摸底
- 2027春：低强度维持
- 2027暑：集中准备 + 第一次正式考试
- 2027秋：必要时二战
- 2028前：语言彻底退出任务列表

而且如果六级 500+ 一次拿下，你的大二下会因此直接多出一块可支配时间，这块时间前期给 **丘赛/Hatcher**，暑假以后再短暂转给 TOEFL，利用率非常高。

但其实**已经不多了**。你现在已经把「成绩、做题、丘赛、暑校、语言」这几条显性的线搭起来了。接下来真正还没被覆盖、而且最终决定顶尖 Math PhD 上限的，主要只剩 **四块**：

### 1. 导师关系与推荐信

这是之后最重要的一块，而且现在就该慢慢开始。钱振烨可以是很好的 mentor，但到申请时，真正有分量的推荐信还是需要**数学 faculty** 来写。你最好到大二结束时做到：

> 至少 1 位本校数学老师真正了解你；
> 大三结束时有 2 位老师能具体评价你的数学能力；
> 最理想再有 1 位外校老师能做 external calibration。

推荐信不是到大四临时找人，而是未来两年自然长出来的。最理想的关系是：上课/讨论班 → reading → 专题报告 → 小问题/research → 强推荐信。你今年可以开始观察：**系里谁最适合长期看你的数学，而不是谁头衔最大。**

### 2. 大三必须开始真正的 research

现在不急。你大二主要还是：basic training + advanced coursework + seminar。但大三开始，就不能一直停留在“我读了很多书”。应该逐渐出现：

> 一个具体问题；
> 一个长期指导你的老师；
> 半年到一年持续工作；
> 自己读文献、做例子、证明 lemma、失败、重新尝试。

最终有没有 paper 不设 KPI。但到申请时，你必须能够认真回答：**“你做过什么数学研究？”** 而不是：“我上过很多暑校、参加过很多 seminar。”如果你冲 Princeton/MIT/Berkeley/Chicago 这种级别，**research potential + recommendation** 最终会比丘赛奖牌本身重要。

### 3. 高阶课程要形成一张漂亮的 transcript

我们现在谈了很多自学，但申请时委员会首先看到的还是正式成绩单。按照你现在 Analysis + Geometry/Topology 的兴趣，大二后半到大三最好逐渐形成类似：Real Analysis / Complex Analysis / Measure Theory / Functional Analysis / Topology / Algebraic Topology / Differential / Riemannian Geometry。再根据方向选 PDE / Probability / Harmonic Analysis 等。如果学校允许，而且你到大三已经有能力，**1–2 门真正合适的研究生课程**会很好。但有一个底线：

> 宁可本科高级课拿 92，也不要为了“我修了研究生课”拿 72。

你现在是需要用后两年的成绩证明自己的人，所以课程深度和成绩要一起漂亮。

### 4. 大三再做一次真正的外部校准

北大几何暑校是第一步，但它主要还是 **summer school / learning environment**。到了大三暑假，我希望你再争取一次更强的：research / supervised reading / serious summer program。可能是国内强校老师、海外暑研、REU 类项目、研究所项目等。这里目标不是再收集一个 logo，而是：**让本校之外的数学家真正见过你做数学。** 如果最后还能拿到一封有内容的外部推荐信，对你这种本科背景会非常有帮助。

## 还有一个东西：Math Subject GRE

这个现在**不要准备**。你是 2028 秋申请，2029 入学，各校到时候政策很可能和现在不同。大三下再检查目标学校：

> 哪些 required；哪些 recommended；哪些不收。

如果届时需要，你有 CMC + 丘赛两年的做题训练，再准备 Math GRE 应该会比现在容易得多。所以暂时：**GRE Math = 大三再说**，不要现在开线程。

## 这样，你整个本科计划其实已经能闭环了

### 大二

成绩翻盘 + CMC 建立做题能力 + Hatcher + Analysis/Geometry 基础 + 丘赛双线试水 + 北大几何暑校 + CET6/TOEFL 逐步解决。同时开始建立 **faculty mentor**。

### 大三

高级课程 + 丘赛正式冲 + 方向逐渐确定 + 真正 research + 强推荐信形成 + 外部科研/校准。

### 大四上

才进入真正的：选校 + SOP + CV + 推荐信提交 + 美国/香港申请。国内考研如果那时候还想保留，再按当年的统考政策决定，不需要现在专门准备。

---

所以现在我反而建议你**停止继续增加计划项**。你目前缺的已经不是：“我是不是还忘了参加什么比赛？” 而是未来两年把这些已经定下来的东西**真的做深**。

最终一个顶尖 Math PhD committee 想看到的其实非常朴素：

- 这个人数学课很强
- 会解决问题
- 学过足够深的数学
- 做过真正研究
- 有数学家愿意强烈推荐他

CMC、丘赛、Hatcher、北大暑校、TOEFL，最终都只是围绕这五件事服务。
