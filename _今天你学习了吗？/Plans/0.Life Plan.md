## What I need to do Next

### 现状分析

最大的问题来自不平衡发展：

- 阅读兴趣 > 做题能力；
- 数学直觉 > 训练量；
- 接触广度 > 基础稳定性。

鉴于此前的分析，大致情况如此：

- 杭师大数学本科，刚大二，无挂科。
- 大一成绩偏弱，尤其数分/高代；但已明确准备通过后续核心课和重修做明显 upward trend。
- 下学期核心课是数分 III、近世代数、基础拓扑、概率，目标基本定在 90 左右或以上。
- 你过去最大的问题不是缺兴趣，而是**几乎不做题，主要靠直觉和临场能力**；现在已经意识到要改变。
- 数学兴趣明显偏纯数学，目前 exposure 较多的是 Fourier / analysis / Kakeya / GMT / topology，但方向暂时不需要定死。
- 钱振烨在带你组织基础讨论班，Fourier 用 Stein，Algebra 用 Artin；这是一条很好的 mentoring / seminar 资源。
- 目标已经从“能不能申美国全奖 PhD”提高成了：**冲美国强校/顶尖 Math PhD**。
- 美国暂时只定“出金 + 高冲”，不考虑保底。
- 香港主要看 CUHK / HKU / HKUST。
- 国内保研基本不考虑，考研路线以后只考虑仍保留纯数学统考、且数学环境真正值得去的地方。
- 核心价值观很明确：**不是为了镀金或出国本身，而是想真正把数学学出来。**

**数学兴趣和主动性已经明显跑在正式成绩前面，但做题量、课程表现、证明熟练度还没有把这种兴趣兑现成硬实力。**

很多数学本科生到大三才开始意识到本科课程之外还有 seminar、reading、research。你刚大二已经开始接触这些，而且不是完全自己乱摸，有一个刚从相近本科环境走出去、现在在 CUHK 读 PhD 的学长带你组织讨论班。

但是现在最大的问题是：很容易：
> 看很多东西、听 seminar、接触高级概念、产生数学直觉，

但是
> **真正坐下来独立解决题目的时间太少。**

靠课堂理解 + 数学感觉能撑到七十多，一旦课程进入需要大量训练、技术熟练和证明细节的阶段，就开始掉下去。有不错的数学直觉和探索欲，但严谨性还需要系统训练。

**GPA** 是最大的短板，以后千万不可以继续读很多高级东西 → 仍然不做题 → 核心课继续七十多 → seminar 看起来很丰富 → 到大三发现基础和 GPA 都没救起来。

> 上限尚未显现，短板非常明显，时间还有，可以冲刺
