# MATLAB数学建模入门 - 第一课：环境与基本计算

## 课程目标
熟悉MATLAB基础环境，掌握基本数学运算和变量操作，为数学建模打下基础。

## 一、认识MATLAB环境

### 三大核心窗口
1. **命令窗口** - 直接输入指令，立即得到结果
2. **工作区** - 显示当前所有变量及其信息
3. **当前文件夹** - 管理脚本文件和数据文件的位置

**重要习惯**：每次启动MATLAB，首先设置工作文件夹为"当前文件夹"

## 二、基本数学运算

### 算术运算符

```matlab
3 + 5 % 加法

7 - 4 % 减法

6 * 8 % 乘法

10 / 2 % 除法

2^3 % 幂运算（2的3次方）
```

### 数学常数和函数

```Matlab

pi % 圆周率 π

sin(pi/2) % 正弦函数

exp(1) % 自然常数e的1次方

log(exp(1)) % 自然对数

sqrt(9) % 平方根
```

**注意**：
- 使用 `%` 添加注释
- 函数名后必须跟括号，参数放在括号内

## 三、变量操作

### 创建和使用变量

```Matlab
a = 10 % 定义变量a并赋值为10

b = 5 % 定义变量b并赋值为5

c = a + b % 计算a+b并赋值给c

c * 2 % 使用变量进行计算
```

### 变量命名规则
- 以字母开头
- 可包含字母、数字、下划线
- 大小写敏感（A ≠ a）
- 不能使用关键字（if, for, end等）

### 实际应用示例

```Matlab
radius = 5 % 定义半径

area = pi * radius^2 % 计算圆面积
```

## 四、第一课练习

### 练习1：物理公式计算
计算匀加速直线运动的位移：`s = v0*t + 0.5*a*t^2`

```Matlab
v0 = 5 % 初始速度

a = 9.8 % 加速度

t = 2 % 时间

s = v0_t + 0.5_a*t^2 % 位移
```

### 练习2：数学函数验证

```Matlab
cos(pi) == -1 % 验证cos(π)是否等于-1

log10(100) % 计算以10为底100的对数
```

### 练习3：工作区探索
- 在工作区窗口双击变量查看详细信息
- 观察变量的名称、值、类型等信息
