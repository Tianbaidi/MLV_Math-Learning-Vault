> Claude 文章主要由五个主定理构成，其中 A 到 C 给出了三个基本的无条件比例下界，D 优化测试函数进一步改善这些函数，E 则用同样的方法推广到本源的 Dirichlet L - Function .这里主要依赖 ChatGPT 来阅读整理，人工做了排版上的工作。

## 2.1 Notion

设 $\rho = \beta + i\gamma$ 为黎曼 $\zeta$ 函数的非平凡零点，$m_{\rho} \ge 1$ 表示其重数。对于 $0 \le T_1 < T_2$，采用如下零点计数记号。论文约定 $N(T) := N(0,T)$，其余计数函数同理。

|        记号        | 含义                                    |
| :--------------: | ------------------------------------- |
|   $N(T_1,T_2)$   | 满足 $T_1<\gamma\le T_2$ 的全部非平凡零点数，按重数计 |
|  $N_d(T_1,T_2)$  | 同一区间内全部互异零点数，每个不同零点只计一次               |
|  $N_0(T_1,T_2)$  | 同一区间内临界线 $\beta=\frac12$ 上的零点数，按重数计   |
| $N_0^*(T_1,T_2)$ | 同一区间内临界线上的互异零点数                       |
| $N_0^s(T_1,T_2)$ | 同一区间内临界线上的简单零点数                       |
|  $N^s(T_1,T_2)$  | 同一区间内全部简单零点数                          |
这些计数函数满足
$$N_0^s \le N_0^* \le N_0 \le N, \quad N_0^s \le N_s \le N_d \le N. \tag{2.1}$$
论文在高度区间 $(T,2T]$ 上使用如下尺度参数。

| 记号 | 定义 | 作用 |
| :---: | :--- | --- |
| $\ell$ | $\displaystyle \log\frac{T}{2\pi}$ | 高度 $T$ 对应的基本对数尺度 |
| $\ell_1$ | $\ell+2\log2-1$ | Riemann–von Mangoldt 主项中的修正尺度 |
| $\lambda$ | $0<\lambda\le1$ | 归一化带宽参数 |
| $L$ | $\lambda\ell$ | 实际 Fourier 支撑尺度 |
| $X$ | $e^L=\left(\frac{T}{2\pi}\right)^\lambda$ | 显式公式中素数幂的截断长度 |
| $\lambda_1$ | $\displaystyle\frac{L}{\ell_1}$ | 有限高度下实际进入主项的归一化带宽 |
| $H(\lambda)$ | $\displaystyle 2-\frac1\lambda-\frac{\lambda}{3}$ | Theorem A、B 的比例函数 |
| $H_d(\lambda)$ | $\displaystyle\frac{1+H(\lambda)}2$ | Theorem C 的第一支比例函数 |
| $F(\lambda)$ | $\displaystyle\frac{\lambda}{1+\lambda^2/3}$ | Theorem C 的第二支比例函数 |

由 Riemann–von Mangoldt 公式，
$$N(T,2T) = \frac{T\ell_1}{2\pi} + O(\ell). \tag{2.2}$$
同时，
$$\ell_1 = \ell + 2\log 2 - 1, \quad \lambda_\ell = \lambda + O\left(\frac{1}{\ell}\right). \tag{2.3}$$
三个比例函数在 $\lambda=1$ 时满足
$$H(1) = \frac{2}{3}, \quad H_d(1) = \frac{5}{6}, \quad F(1) = \frac{3}{4}. \tag{2.4}$$
此外，
$$H_d(\lambda) \ge F(\lambda) \iff H(\lambda) \ge 0 \iff \lambda \ge 3 - \sqrt{6}. \tag{2.5}$$
式 (2.5) 将决定 Theorem C 证明中两种估计的分界点。

## 2.2主定理

Theorem A–C 的证明最终只需要两类结果：

- 零点侧给出的计数不等式；
    
- 素数侧给出的矩估计。

这些结果本身将在后面的章节中构造和证明；本节只固定其主定理证明所需要的形式。
令 $I = [T, 2T]$，取 $D_0 = T^{1/2}$。论文由 Weil Hermitian 型构造有限维矩阵 $G$，并使用归一化
$$\widehat{G} := \frac{G}{L}, \quad \widetilde{G} := \frac{G}{a L^2}, \tag{2.6}$$
其中
$$a := \frac{1}{L} \int_{\mathbb{R}} \phi(u)^2 \, du.$$
关于 $G, \widehat{G}, \widetilde{G}$ 的具体构造留待 [[5. 特自构造]] 讨论。

### 2.2.1主定理前置估计

#### 2.2.1.1 Prop.4.4-4.5 零点计数估计

Proposition 4.4 对于临界线上的互异零点，
$$N_0^*(T,2T) \ge 4\operatorname{tr}\widehat{G} - \Vert{}\widehat{G}\Vert{}_F^2 - 2N(T,2T) - R_T. \tag{2.7}$$
对于临界线上的简单零点，
$$N_0^s(T,2T) \ge 4\operatorname{tr}\widehat{G} - \Vert{}\widehat{G}\Vert{}_F^2 - 2N(T,2T) - R_T. \tag{2.8}$$
对于全部互异零点，
$$N_d(T,2T) \ge \frac{1}{2}\left(4\operatorname{tr}\widehat{G} - \Vert{}\widehat{G}\Vert{}_F^2 - N(T,2T)\right) - R_T. \tag{2.9}$$
其中误差 $R_T$ 来自高度窗口以外零点的尾项，并满足
$$R_T = O\left(\theta_0 L^{-1}(1 + \Vert{}\widehat{G}\Vert{}_F) + D_0 \ell\right). \tag{2.10}$$
这些不等式是 Theorem A、B 以及 Theorem C 第一种估计的直接零点侧输入。

Proposition 4.5。若 $\theta \ge \theta_0$，则
$$N_d(T,2T) \ge n_\theta^+(\widehat{G}) - N(I' \setminus I), \tag{2.11}$$
其中 $n_\theta^+(\widehat{G})$ 表示 $\widehat{G}$ 中严格大于 $\theta$ 的特征值个数，而
$$N(I' \setminus I) \ll D_0 \ell. \tag{2.12}$$
这一 Prop. 则用在 Theorem C 的另一种估计上。

#### 2.2.1.2 素数侧矩估计

取窗宽 $w=1$。由 Theorem 5.8，
$$\operatorname{tr} G = a L N(T,2T) + O(LX), \tag{2.13}$$
且
$$\operatorname{tr}(G^2) = \frac{TL}{2\pi} \left(\ell_1^2 + \frac{L^2}{3}\right) (1 + O(E_T')), \tag{2.14}$$
其中$E_T' \ll_{\lambda} \frac{\log \ell}{\ell} \qquad{(2.15)}$,  而当 $\lambda < 1$ 时可加强为 $E_T' \ll_{\lambda} \ell^{-1}$。由于 $a = 1 + O(L^{-1})$，将 (2.13)–(2.14) 换到 $\widehat{G}$ 的归一化后，可写成
$$\operatorname{tr}\widehat{G} = N(T,2T)(1 + o(1)), \tag{2.16}$$
以及
$$\Vert{}\widehat{G}\Vert{}_F^2 \le \left( \frac{1}{\lambda_1} + \frac{\lambda_1}{3} \right) N(T,2T) (1 + O(E_T')). \tag{2.17}$$
此外，
$$\frac{(\operatorname{tr} G)^2}{\operatorname{tr}(G^2)} = F(\lambda_1) N(T,2T) (1 + O(E_T')). \tag{2.18}$$
式 (2.16)–(2.17) 是 Theorem A、B 与 Theorem C 第一支估计的主要算术输入；式 (2.18) 则负责 Theorem C 的第二支 $F(\lambda)$。

### 2.2.2 主定理展开

#### Theorem A ：临界线上的互异零点
**Theorem A.** 固定 $0 < \lambda \le 1$。则存在常数 $c(\lambda) > 0$ 与 $T_0(\lambda) > 0$，使得对于所有 $T \ge T_0(\lambda)$，
$$N_0^*(T,2T) \ge \left( H(\lambda) - c(\lambda) \frac{\log\log T}{\log T} \right) N(T,2T). \tag{2.19}$$
若 $\lambda < 1$，则式 (2.19) 中的 $\log\log T$ 因子可以去掉。特别地，
$$\liminf_{T \to \infty} \frac{N_0^*(T,2T)}{N(T,2T)} \ge \frac{2}{3}, \tag{2.20}$$
且
$$\liminf_{T \to \infty} \frac{N_0^*(T)}{N(T)} \ge \frac{2}{3}. \tag{2.21}$$
因此当然也有 $N_0(T) \ge \left(\frac{2}{3} - o(1)\right) N(T)$。

**Proof.** 简记 $N := N(T,2T)$。由 (2.7)、(2.16) 与 (2.17)，
$$\begin{aligned}
N_0^*(T,2T) &\ge 4N - \left( \frac{1}{\lambda_1} + \frac{\lambda_1}{3} \right) N - 2N - O(E_T' N) \\ &= \left( 2 - \frac{1}{\lambda_1} - \frac{\lambda_1}{3} - O(E_T') \right) N \\ &= (H(\lambda_1) - O(E_T')) N.  
\end{aligned}\tag{2.22}$$
这里由 $\Vert{}\widehat{G}\Vert{}_F \ll N^{1/2}$、$D_0 = T^{1/2}$ 及尾项估计可知，$R_T$ 相比主项可吸收到 $O(E_T' N)$ 中。令 $c_0 := 2\log 2 - 1$。由$\displaystyle \frac{1}{\lambda_1} = \frac{\ell + c_0}{\lambda \ell},$ 直接计算可得
$$H(\lambda) - H(\lambda_1) = \frac{c_0}{\lambda \ell} - \frac{\lambda - \lambda_1}{3} < \frac{1}{\lambda \ell}.$$
因此
$$H(\lambda_1) \ge H(\lambda) - \frac{1}{\lambda \ell}. \tag{2.23}$$
结合 $\ell \asymp \log T$ 与 (2.15)，由 (2.22) 得
$$N_0^*(T,2T) \ge \left( H(\lambda) - c(\lambda) \frac{\log\log T}{\log T} \right) N(T,2T).$$
- 若 $\lambda < 1$，则 $E_T' \ll_{\lambda} \ell^{-1}$，所以误差项中的 $\log\log T$ 可以去掉。

- 取 $\lambda = 1$，由 $H(1) = 2/3$ 得到 (2.20)。

最后证明整体形式 (2.21)。给定 $\varepsilon > 0$，取 $T_1$ 足够大，使所有 $t \ge T_1$ 都满足
$$N_0^*(t,2t) \ge \left( \frac{2}{3} - \varepsilon \right) N(t,2t).$$
将 $(T_1, T]$ 分解成 dyadic intervals 并逐段求和，可得
$$N_0^*(T) \ge \left( \frac{2}{3} - \varepsilon \right) N(T) - O_{\varepsilon}(1).$$
先令 $T \to \infty$，再令 $\varepsilon \to 0$，即可得到 (2.21)。 $\displaystyle \square$ 

#### Theorem B ：临界线上的简单零点
**Theorem B.** 在 Theorem A 相同的假设下，
$$N_0^s(T,2T) \ge \left( H(\lambda) - c(\lambda) \frac{\log\log T}{\log T} \right) N(T,2T). \tag{2.24}$$
特别地，
$$\liminf_{T \to \infty} \frac{N_0^s(T)}{N(T)} \ge \frac{2}{3}. \tag{2.25}$$
换言之，至少三分之二的零点可以无条件证明既位于临界线上，又为简单零点。

**Proof.** 由零点侧不等式 (2.8)，
$$N_0^s(T,2T) \ge 4\operatorname{tr}\widehat{G} - \Vert{}\widehat{G}\Vert{}_F^2 - 2N - R_T.$$

代入与 Theorem A 完全相同的矩估计，得到
$$\begin{aligned} N_0^s(T,2T) &\ge 4N - \left( \frac{1}{\lambda_1} + \frac{\lambda_1}{3} \right) N - 2N - O(E_T' N) \\ &= (H(\lambda_1) - O(E_T')) N.  \end{aligned}\tag{2.26}$$
再利用 (2.23) 即得 (2.24)。取 $\lambda=1$，并按照 Theorem A 的 dyadic summation，同样得到 (2.25)。$\displaystyle \square$

#### Theorem C：全部互异零点
**Theorem C.** 固定 $0 < \lambda \le 1$。对于充分大的 $T$，
$$N_d(T,2T) \ge \left( \max\{H_d(\lambda), F(\lambda)\} - c(\lambda) \frac{\log\log T}{\log T} \right) N(T,2T). \tag{2.27}$$
特别地，
$$\liminf_{T \to \infty} \frac{N_d(T)}{N(T)} \ge \frac{5}{6}. \tag{2.28}$$

**Proof.** 由于 (2.5) 中 $H_d$ 与 $F$ 的大小关系发生改变，证明分为两种情形。

- **情形一：** $\lambda \ge 3 - \sqrt{6}$
	此时 $H_d(\lambda) \ge F(\lambda)$。由 (2.9) 以及 (2.16)–(2.17)，
	$$\begin{aligned} N_d(T,2T) &\ge \frac{1}{2}\left[4 - \frac{1}{\lambda_1} - \frac{\lambda_1}{3} - 1\right] N - O(E_T' N) \\ &= (H_d(\lambda_1) - O(E_T')) N.  \end{aligned}\tag{2.29}$$
	由于 $H_d' = \frac{1}{2} H'$，且 $\lambda_1 = \lambda + O(\ell^{-1})$，有
	$$H_d(\lambda_1) = H_d(\lambda) + O_{\lambda}(\ell^{-1}).$$
	于是
$$N_d(T,2T) \ge (H_d(\lambda) - O(E_T')) N. \tag{2.30}$$

- **情形二：** $0 < \lambda < 3 - \sqrt{6}$

	此时应使用 **阈值正特征值估计**。
	
	由 **尾项估计**，$\theta_0 \ll \ell T^{\lambda/2 - 1}$。另一方面，**素数侧迹** 给出 $\operatorname{tr}\widehat{G} / d \asymp \ell$，故当 $T$ 足够大时，
	$$\operatorname{tr}\widehat{G} > \theta_0 d.$$
	由 **阈值柯西–施瓦茨不等式**，
	$$n_{\theta_0}^+(\widehat{G}) \ge \frac{(\operatorname{tr}\widehat{G} - \theta_0 d)^2}{\operatorname{tr}(\widehat{G}^2)}. \tag{2.31}$$
	又因为$\displaystyle \frac{\theta_0 d}{\operatorname{tr}\widehat{G}} = O(E_T'),$ 结合 (2.18) 可得
	$$n_{\theta_0}^+(\widehat{G}) \ge F(\lambda_1) N (1 + O(E_T')). \tag{2.32}$$
	再使用 (2.11)，以及 $N(I' \setminus I) \ll T^{1/2} \ell$，得到
	$$N_d(T,2T) \ge (F(\lambda_1) - O(E_T')) N. \tag{2.33}$$
	在 $[0,1]$ 上，
	$$F'(x) = \frac{1 - x^2/3}{(1 + x^2/3)^2} \in (0,1].$$
	因此，由 $0 \le \lambda - \lambda_1 \ll \ell^{-1}$，可得
	$$F(\lambda_1) \ge F(\lambda) - O(\ell^{-1}). \tag{2.34}$$
	于是
	$$N_d(T,2T) \ge (F(\lambda) - O(E_T')) N. \tag{2.35}$$
	综合 (2.30) 与 (2.35)，即得到 (2.27)。
	最后取 $\lambda = 1$。由于 $H_d(1) = 5/6 > F(1) = 3/4$，有
	$$\liminf_{T \to \infty} \frac{N_d(T,2T)}{N(T,2T)} \ge \frac{5}{6}.$$
	再作与 Theorem A 相同的 **二进求和**，即得到 (2.28)。 $\displaystyle \square$

#### Theorem D：最优测试窗

上述的基础常数均来自平顶的测试窗。论文进一步优化测试函数并且恢复 Montgomery - Taylor 的最优核, 令
$$\phi(u)^2 = v(u/L), \quad -\frac{1}{2} \le \frac{u}{L} \le \frac{1}{2}.$$
相应的尺度无关泛函为
$$c_\lambda(v) := \frac{\lambda \left(\int v\right)^2}{\int v^2 + \lambda^2 \iint \vert{}s-s'\vert{} v(s) v(s') \, ds \, ds'}, \quad v \ge 0. \tag{2.36}$$
定义积分算子
$$(Tv)(s) := \int_{-1/2}^{1/2} \vert{}s-s'\vert{} v(s') \, ds'. \tag{2.37}$$
极值条件可写为 $v + \lambda^2 Tv = \text{const} \qquad (2.38)$, 由于
$$\frac{d^2}{ds^2} \vert{}s-s'\vert{} = 2\delta(s-s'),$$
对 (2.38) 作二次求导，得到 $v'' + 2\lambda^2 v = 0. \qquad(2.39)$ , 因而最优轮廓为
$$v_\lambda^*(s) = \cos(\sqrt{2}\lambda s), \quad \vert{}s\vert{} \le \frac{1}{2}, \tag{2.40}$$
且
$$c_\lambda^* = \frac{\sqrt{2}\tan\vartheta}{1 + \vartheta \tan\vartheta}, \quad \vartheta = \frac{\lambda}{\sqrt{2}}. \tag{2.41}$$
特别地，
$$c_1^* = \frac{2\tan(1/\sqrt{2})}{\sqrt{2} + \tan(1/\sqrt{2})} = 0.7532960\dots \tag{2.42}$$
**Theorem D**  有
$$\liminf_{T \to \infty} \frac{N_0^*(T,2T)}{N(T,2T)} \ge 2 - \frac{1}{c_1^*} = \frac{3}{2} - \frac{1}{\sqrt{2}} \cot \frac{1}{\sqrt{2}} = 0.67250\dots \tag{2.43}$$
以及
$$\liminf_{T \to \infty} \frac{N_0^s(T,2T)}{N(T,2T)} \ge 2 - \frac{1}{c_1^*} = 0.67250\dots \tag{2.44}$$
并且
$$\liminf_{T \to \infty} \frac{N_d(T,2T)}{N(T,2T)} \ge \frac{1}{2} \left( 3 - \frac{1}{c_1^*} \right) = 0.83625\dots \tag{2.45}$$

**Proof.**  取 $\lambda=1$，并选择在端点经过固定宽度平滑处理的最优窗
$$\phi(u) = \cos\left(\frac{\sqrt{2}u}{\ell}\right)^{1/2} \varrho(L/2 - \vert{}u\vert{}). \tag{2.46}$$
在其支撑上，
$$\cos\left(\frac{\sqrt{2}u}{\ell}\right) \ge \cos \frac{1}{\sqrt{2}} > 0,$$
因此该窗仍满足前文建立 **零点侧估计** 与 **素数侧估计** 所要求的正则性条件。相应的 **迹比** 满足
$$\frac{(\operatorname{tr} G)^2}{\operatorname{tr}(G^2)} = \frac{1}{c_{\lambda_1}^*} N(T,2T) \left(1 + O\left(\frac{\log \ell}{\ell}\right)\right), \tag{2.47}$$
且 $c_{\lambda_1}^* = c_1^* + O(\ell^{-1})$。在 $\widehat{G}$ 的归一化下，
$$\operatorname{tr}\widehat{G} = N(T,2T) (1 + O(T^{-1/2})), \tag{2.48}$$
而
$$\Vert{}\widehat{G}\Vert{}_F^2 = N(T,2T) \left( \frac{1}{c_{\lambda_1}^*} + O\left(\frac{\log \ell}{\ell}\right) \right). \tag{2.49}$$
因此 Theorem A–C 的证明无需改变，只需将其中 $H(\lambda)$ 替换为
$$2 - \frac{1}{c_\lambda^*},$$
并相应将 $H_d$ 替换为 $\frac{1}{2}\left(3 - \frac{1}{c_\lambda^*}\right)$。于是得到 (2.43)–(2.45)。 $\displaystyle \square$ 

#### Theorem E ：本原 Dirichlet L - 函数

设 $\chi$ 为模 $q>1$ 的固定本原 Dirichlet 特征。记 $N_\chi, N_{0,\chi}^*, N_{0,\chi}^s, N_{d,\chi}$ 为 $L(s,\chi)$ 对应的零点计数函数。此时
$$N_\chi(T,2T) = \frac{T}{2\pi} \log \frac{qT}{2\pi} + O(T). \tag{2.50}$$
**Theorem E.** 固定 $q$ 与本原特征 $\chi \pmod q$。对于任意固定 $0 < \lambda \le 1$，当 $T$ 足够大时，
$$N_{0,\chi}^*(T,2T) \ge (H(\lambda) - o(1)) N_\chi(T,2T), \tag{2.51}$$
$$N_{0,\chi}^s(T,2T) \ge (H(\lambda) - o(1)) N_\chi(T,2T), \tag{2.52}$$
以及
$$N_{d,\chi}(T,2T) \ge (\max\{H_d(\lambda), F(\lambda)\} - o(1)) N_\chi(T,2T). \tag{2.53}$$
因此至少 $(2/3 - o(1)) N_\chi(T,2T)$ 个零点位于临界线上，至少相同比例的零点同时简单且位于临界线上，并且至少 $(5/6 - o(1)) N_\chi(T,2T)$ 个零点互异。Theorem D 的优化结果同样成立。

**Proof.** 证明完全沿用 Theorem A–D，只需要检查以下三处变化。

1) 显式公式
	
	令
	$$\kappa := \frac{1 - \chi(-1)}{2}.$$
	Archimedean density 改为
	$$\mu_\chi(\tau) = \frac{1}{2\pi} \left[ \log \frac{q}{\pi} + \operatorname{Re} \frac{\Gamma'}{\Gamma} \left( \frac{1}{4} + \frac{\kappa}{2} + \frac{i\tau}{2} \right) \right], \tag{2.54}$$
	而 prime term 变为
	$$P_{X,\chi}(\tau) = -\frac{1}{\pi} \operatorname{Re} \sum_{n \le X} \Lambda(n) \chi(n) n^{-1/2 - i\tau}. \tag{2.55}$$
	由于 $L(s,\chi)$ 不具有 $\zeta(s)$ 在 $s=1$ 的极点，因此这里没有对应的 $\Pi_X$ 项。
	
2) 零点侧
	
	由函数方程与共轭关系，零点多重集在
	$$\rho \longmapsto 1 - \bar{\rho}$$
	下仍然保持不变，并保留重数。因此第 4 节中关于临界线零点和离线零点对的 block decomposition 原样成立。
	
3) 素数侧
	
	有
$$\vert{}\Lambda(n) \chi(n)\vert{} = \Lambda(n) \mathbf{1}_{(n,q)=1}. \tag{2.56}$$
	因为 $q$ 固定，这与 $\zeta$ 情形相比只删除有限多个素数；其余系数仅乘上模为 1 的因子 $\chi(n)$。因此 prime diagonal 不变，Montgomery–Vaughan 型估计也仅通过系数绝对值受到影响。将 $\ell_1$ 替换为
	$$\ell_{1,\chi} := \log \frac{qT}{2\pi} + 2\log 2 - 1, \tag{2.57}$$
	则对于固定 $q$，有 $L/\ell_{1,\chi} \to \lambda$。于是 Theorem A–D 的全部证明可以逐项移植，从而得到 (2.51)–(2.53)。
           $\displaystyle \square$
