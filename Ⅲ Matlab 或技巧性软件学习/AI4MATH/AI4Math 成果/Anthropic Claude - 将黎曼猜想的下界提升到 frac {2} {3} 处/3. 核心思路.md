 设有限维压缩得到 Hermitian 矩阵 $\widehat{G}$。Cauchy–Schwarz 对其特征值给出
$$n_+(\widehat{G}) \ge \frac{(\operatorname{tr}\widehat{G})^2}{\operatorname{tr}(\widehat{G}^2)}.$$
而 prime side 无条件给出
$$\operatorname{tr}\widehat{G} \sim N, \quad \operatorname{tr}(\widehat{G}^2) \sim \frac{4}{3} N \quad (\lambda=1).$$
所以
$$n_+(\widehat{G}) \ge \frac{N^2}{\frac{4}{3}N} = \frac{3}{4}N.$$
现在利用零点对称性。临界线外的零点以 $\{\rho, 1-\bar{\rho}\}$ 成对出现，而每一个这样的 pair 产生一个 $\operatorname{signature}(1,1)$ 的 block。因此：

- 两个离线零点最多只能解释一个 positive direction。
    
于是若至少有 $\frac{3}{4}N$ 个 positive directions，则最坏情况下：
- $\frac{3}{4}N$ 个正方向中尽可能多来自离线 pair。
    
每个 pair 消耗两个零点，因此最终仍被迫剩下
$$2 \cdot \frac{3}{4}N - N = \frac{1}{2}N$$

个在线零点。这就是最初出现的 $\frac{1}{2}$。论文正是这样描述第一版结果的。

把有限压缩写成
$$\widehat{G} = P + Q.$$
其中：
$$P \succeq 0$$
来自临界线零点，并满足
$$\operatorname{rank} P \le N_0^*;$$
而 $Q$ 来自离线 pairs，每一对产生 $\operatorname{signature}(1,1)$，所以
$$n_+(Q) \le p.$$
之前的 Cauchy–Schwarz 只研究整个 $\widehat{G}$：
$$n_+(\widehat{G}).$$
这丢掉了 $\widehat{G} = P + Q$ 的内部结构。
新的问题应该是：

<center>能不能直接从 $\widehat{G} = P + Q$ 估计 $\operatorname{rank} P$？</center>

新的子 agent 注意到 秩-迹不等式
$$\operatorname{rank} P \ge 2\operatorname{tr} P + 4\operatorname{tr} Q - 4n_+(Q) - \Vert{}P+Q\Vert{}_F^2.$$
它其实是 Montgomery 原来
$$m^2 \ge 2m - 1$$
的矩阵版本。于是代入：
$$\operatorname{tr}\widehat{G} \sim N,$$
$$\Vert{}\widehat{G}\Vert{}_F^2 \sim \left( \frac{1}{\lambda} + \frac{\lambda}{3} \right) N,$$
最终得到
$$N_0^* \ge \left( 2 - \frac{1}{\lambda} - \frac{\lambda}{3} - o(1) \right) N.$$
取 $\lambda = 1$，便有
$$2 - 1 - \frac{1}{3} = \frac{2}{3}.$$
